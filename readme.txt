Tag and organize WooCommerce customers.

== Description ==

Customer Tagger helps you label and manage customers from the WordPress admin.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Open **Customer Tagger** in the admin menu.
